**Five-dataset leave-one-time-point-out benchmark across methods.** (a) Number of benchmark settings in which each method had the lowest mean Sliced-W2 among the applicable methods. The 33 settings span matched datasets, held-out time points, and evaluation spaces. CytoBridge had the lowest value in 12 settings, Linear OT displacement in 11, PASTE in 6, stVCR in 2, and MOSCOT in 2. Random interpolation did not have the lowest value in any setting. Linear OT displacement is included as a geometric interpolation control. (b–f) Relative Sliced-W2 compared with CytoBridge for Zebrafish, MOSTA, ARISTA, AD mouse, and chicken heart. Positive values indicate lower error for CytoBridge. Open circles represent held-out time points, diamonds represent means, and error bars show the standard error across held-out time points. Overall values are calculated for each held-out time point by averaging the joint, spatial, and state relative errors. MIOFlow, STORIES, and Waddington-OT are shown only for state space because they do not provide benchmark spatial coordinates. Each target-space Sliced-W2 value was averaged over five shared random-projection repeats before ranking or comparison.
