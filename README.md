# CytoBridge

CytoBridge is the core codebase for preprocessing, spatial alignment, model training, checkpoint loading, and downstream analysis on time-series spatial transcriptomics data.

## Scope

This repository contains:

- the installable Python package `CytoBridge/`
- training implementation modules in `CytoBridge/tl/train/`
- the project-level preprocessing workflow in `scripts/`
- preprocessing-side edge predictor training utilities in `CytoBridge/pp/edge_prediction.py`

## Repository Layout

```text
cb_pipeline/
├── CytoBridge/
│   ├── pp/        # preprocessing, spatial alignment, interaction graph construction
│   ├── tl/        # training internals, model utilities, and downstream analysis helpers
│   ├── pl/        # visualization helpers
├── scripts/       # project-level preprocessing workflow
├── environment.yml
├── requirements.txt
└── README.md
```

## Installation

```bash
git clone <your-repo-url>
cd cb_pipeline

conda env create -f environment.yml
conda activate cb_pipeline
pip install -e .
```

## Input Requirements

The main preprocessing pipeline expects an input `.h5ad` file with:

- spatial coordinates in `adata.obsm["spatial"]` or `adata.obs["spatial_x"]`, `adata.obs["spatial_y"]`
- a time annotation column in `adata.obs[time_key]`

For interaction graph construction, the pipeline also expects a ligand-receptor database CSV supplied by the user:

```text
/path/to/database/ligand_receptor_database.csv
```

In our internal runs, the database files were organized under a separate `database/` directory and passed explicitly with `--database-path`.

## Quick Start

### Run preprocessing, spatial alignment, interaction graph construction, and edge predictor training

```bash
python scripts/preprocess_pipeline.py \
  --data-name mosta \
  --h5ad-path /path/to/input.h5ad \
  --time-key timepoint \
  --output-dir ./results/mosta_preprocess \
  --database-path /path/to/database/ligand_receptor_database.csv \
  --device cuda
```

This step produces:

- aligned outputs (`*_aligned.csv`, `*_aligned.h5ad`)
- per-timepoint graph inputs in `input_graph/`
- metadata files in `metadata/`
- a trained edge predictor checkpoint under the run output directory

### Load a pretrained CytoBridge model for downstream analysis

```python
from CytoBridge.tl import load_dynamical_model_from_dir

loaded = load_dynamical_model_from_dir(
    "/path/to/pretrained_model_dir"
)
```

## Training Code Organization

- `CytoBridge/tl/train/trainer.py`: core implementation of the CytoBridge dynamical-model training pipeline
- `CytoBridge/pp/edge_prediction.py`: edge predictor training and checkpoint preparation
- `scripts/preprocess_pipeline.py`: project-level preprocessing workflow that prepares graph inputs and edge predictor checkpoints

## Outputs

Typical preprocessing and downstream outputs include:

- aligned `.csv` and `.h5ad` files
- graph inputs and metadata
- trained edge predictor checkpoints generated during preprocessing
- pretrained model directories for downstream loading
- figures and downstream artifacts generated by analysis scripts
