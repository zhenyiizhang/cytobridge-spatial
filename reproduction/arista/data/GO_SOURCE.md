# GO BP 2023 input for ARISTA S22

`GO_Biological_Process_2023.gmt` is the unchanged 1.4-MB input retained in the
24 August 2026 ARISTA calculation, copied from
`figure5c_hotspot_expression_inputs_v1/GO_Biological_Process_2023.gmt` in that run.
It is the Enrichr GO Biological Process 2023 gene-set library, available from the
[Enrichr library endpoint](https://maayanlab.cloud/Enrichr/geneSetLibrary?mode=text&libraryName=GO_Biological_Process_2023).
The retained source does not identify a more specific daily GO release; we do
not infer one. No terms or genes have been modified for this tutorial.

The retained file has SHA-256
`4be7e1b5ed62ab3a8a4837743fa8c9520fc572c5d28dcad8478ed136189908b9`.
This identifies the fixed scientific input, not a requirement to compare hashes
at each notebook run. Its enrichment statistics are recalculated from the
model-derived gene programs and expressed-gene background.
