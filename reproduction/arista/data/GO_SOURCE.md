# Gene Ontology input

`GO_Biological_Process_2023.gmt` is the Enrichr GO Biological Process 2023
library, available from the [Enrichr library endpoint](https://maayanlab.cloud/Enrichr/geneSetLibrary?mode=text&libraryName=GO_Biological_Process_2023).
It is used to calculate enrichment for the model-derived gene programs.
