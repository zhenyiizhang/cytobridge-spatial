# ARTISTA GO enrichment: Supplementary Figure S27

These clusterProfiler tables use 1,736 mapped background genes. Pattern 1 has
ten significant GO terms after BH correction; pattern 2 has none. The panels
show the twenty terms with the lowest unadjusted P values in each pattern.

Calculate enrichment with `reproduction/arista/enrich_go.R` and draw the
panels with `reproduction/arista/clusterprofiler_plots.py`. The
[ARTISTA tutorial](../../../../docs/tutorials/paper_figures/arista_figures.ipynb)
starts from the gene-program calculation and runs both steps.
