# Source data

`composition_endpoint_t2p5.csv` contains the endpoint proportions displayed as
vertical stacked bars. The full spatial particle arrays and saved edge arrays
are from the formal Trem2 whole-tissue scale-1.0 r2 run. The published
`admouse_perturbation_data.zip` supplies these under
`data/admouse/trem2/figure_source`. The renderer uses the included
`scripts/admouse_trem2_plot.py` module.
