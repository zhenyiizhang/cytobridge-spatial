# AD NicheNet analysis

The calculation simulates 51 populations at intervals of 0.05 model time,
reconstructs gene expression, and evaluates NicheNet ligand activity over
50 adjacent time intervals. The input includes the CytoBridge model and
NicheNet ligand–target and ligand–receptor networks.

Use the portable commands in `reproduction/admouse/nichenet/`. The
[AD figure guide](../../../../../../docs/tutorials/paper_figures/admouse_figures.md)
shows the download, interpolation, scoring and plotting steps for S34.
