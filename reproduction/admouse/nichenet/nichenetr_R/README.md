# NicheNet R functions

These six unmodified source files are from the NicheNet R functions used in
the AD analysis, supplied with the collaborator's figure code. They are
distributed under NicheNet's GPL-3 license, included in this directory.

Upstream: https://github.com/saeyslab/nichenetr

Reference: Browaeys, Saelens and Saeys. NicheNet: modeling intercellular
communication by linking ligands to target genes. Nature Methods (2020).
https://doi.org/10.1038/s41592-019-0667-5

CytoBridge's AD scripts prepare model-derived expression inputs, call these
functions, and plot the returned activities and weighted ligand–receptor links.
The scoring and network-plotting functions in this folder are NicheNet code,
not CytoBridge implementations.
