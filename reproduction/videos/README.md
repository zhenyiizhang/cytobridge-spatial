# Supplementary videos

See the [video tutorial](../../docs/tutorials/supplementary_videos.md) for data
downloads and commands.

- `simulate.py` calculates cell states, labels and interactions for MOSTA, ARTISTA and AD mouse.
- `render.py` draws Videos 1–3 from these arrays.
- `support.py` counts the cell edges supporting the MOSTA interaction arrows.
- `zebrafish.py` draws the baseline and virtual-removal comparisons in Videos 4–5.

Run modules from the repository root, for example:

```bash
python -m reproduction.videos.render --help
```
