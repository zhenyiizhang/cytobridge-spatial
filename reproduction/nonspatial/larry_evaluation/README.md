# LARRY model comparison: Supplementary Figure S5

The comparison uses three LR Full models and three No-interaction models.
Distribution error is averaged over simulation repeats within each model,
then over the three models. For clone-fate agreement, predicted fate
probabilities are averaged across models before scoring the 1,237 lineages.

The [S5 tutorial](../../../docs/tutorials/paper_figures/weinreb_s4.ipynb)
calculates these summaries from the individual simulation results. The
[LARRY and scNT tutorial](../../../docs/tutorials/paper_figures/nonspatial_figures.ipynb)
also covers model fields and cell–cell interactions.

`raw/` contains simulation errors and per-lineage probabilities. `summary/`
contains the resulting comparison tables. The
[model download](https://github.com/zhenyiizhang/cytobridge-spatial/releases/tag/weinreb-s4-20261029)
provides the six checkpoints and matching prepared data for repeating inference.
