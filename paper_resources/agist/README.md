# AGIST figure inputs

This folder contains numerical results and figure resources for Figure 2 and
Supplementary Figures S2–S3. `metrics/` contains field agreement, growth and
attention summaries. `layout/` contains the plotted panels.

For data generation, training and plotting, follow the
[AGIST tutorial](../../docs/tutorials/paper_figures/agist_simulations.md).
The [Figure 2 notebook](../../docs/tutorials/paper_figures/main_figure_2.ipynb)
calculates the comparisons and draws the panels.
