# MOSTA figure resources

This folder supplies the numerical inputs and plotting code for Figure 4 and
Supplementary Figures S16–S23. Generated intermediate stages start from the
E12.5 population. The cell-type classifier uses k=10 spatial voting.

Run the [Figure 4 notebook](../../docs/tutorials/paper_figures/main_figure_4.ipynb)
for the main panels, then the [MOSTA supplementary notebook](../../docs/tutorials/paper_figures/mosta_figures.ipynb)
for growth, lineage transitions, gene programs and ligand–receptor analysis.
