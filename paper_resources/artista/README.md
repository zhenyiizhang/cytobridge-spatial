# ARTISTA figure resources

Numerical inputs and plotting functions for the axolotl brain-regeneration
analysis. The model uses 46,199 observed cells from five sections, with
50 gene-expression principal components and two spatial coordinates.

Start with the [ARTISTA tutorial](../../docs/tutorials/dataset_workflows/arista.ipynb),
then continue to [Figure 5](../../docs/tutorials/paper_figures/main_figure_5.ipynb)
and [S24–S30](../../docs/tutorials/paper_figures/arista_figures.ipynb).
These guides specify the model downloads and the calculation for each panel.
