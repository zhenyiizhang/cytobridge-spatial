# Cell-type labels along simulated lineages

These tables store classifier predictions for simulated cells. They are used
to count cell-type transitions between consecutive times along each particle
lineage.

The [MOSTA](../../docs/tutorials/dataset_workflows/mosta.ipynb),
[ARTISTA](../../docs/tutorials/dataset_workflows/arista.ipynb) and
[zebrafish](../../docs/tutorials/paper_figures/zebrafish_si_s31_s38.ipynb)
tutorials show how to simulate populations, assign labels and draw the
resulting lineage summaries.
